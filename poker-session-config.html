📊 Диапазоны рук

Формат диапазона: можно использовать стандартную покерную нотацию: пары (22+), одномастные (A2s+, KTs+), разномастные (ATo+, KQo). Необязательно – это просто текст для отображения.

🎯 Выбор стадий, групп и категорий рук

Флоп

Группы флопов загружаются из матрицы. Категории — из списка HAND_CATEGORIES.

Терн

Типы терна: оверкарта, андеркарта, спарка. Категории — общие.

Ривер

Можно выбрать несколько линий — раздачи объединятся
Типы ривера: не спарилась, спарилась. Категории — общие. Выберите линии, которые будете отрабатывать.

🃏 Флоп

Подсказка: конкретные карты можно выбрать вручную. При выборе текстуры или случайного флопа карты будут сгенерированы автоматически.
